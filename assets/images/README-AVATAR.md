# Profile Avatar Instructions

To add your profile photo:
1. Name your photo file: `my-avatar.png`
2. Place it in this directory: `assets/images/` (overwriting the empty placeholder `my-avatar.png`)
3. Recommended resolution: Square (e.g., 300x300 pixels or higher, JPG or PNG)
4. The portfolio sidebar is preconfigured to display it seamlessly with rounded corners and consistent dimensions (80x80 on mobile, 150x150 on desktop).
